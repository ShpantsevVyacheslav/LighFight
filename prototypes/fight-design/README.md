# Mobile fight selection prototype
Open http://127.0.0.1:8765/prototypes/fight-design/ with repository-root Python HTTP server.
Mobile game layout: fighter stage, power plus three illustrative stats, two fighter choices, arena card, rules drawer. Portrait and landscape CSS. GLBs exported from existing combat FBXs, with guard extracted from jab at phase1/6 and a subtle local breathing loop; existing jab is playable. Model-viewer supports orbit and pinch zoom. Dance is explicitly a placeholder: no Meshy credits spent. Power/stat numbers illustrate design, not real progression. Start button is a prototype toast, not Unity launch. Physical phone gestures remain untested. Existing Unity runtime/build unaffected.
