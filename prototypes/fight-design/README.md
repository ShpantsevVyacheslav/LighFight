# LighFight interaction design prototype
Serve repository root with `python3 -m http.server 8765 --bind 127.0.0.1`, open http://127.0.0.1:8765/prototypes/fight-design/.
Three views: match setup, real GLB orbit/pinch viewer, battle controls mockup. Two fighter models, three arena previews, rule controls, four limb buttons, held guard, bounded pointer joystick, pause/return. Responsive portrait/landscape layouts.
Dance is deliberately an interface placeholder (CSS sway/auto-orbit); strike previews are still frames, not animation playback. Battle backdrop is an existing Unity screenshot, not live combat. Rule controls currently edit prototype selections only. No new Unity combat, hit detection, sidestepping or Meshy generation is included. Future implementation must use swept limb hit volumes against opponent hurt volumes, prevent duplicate active-window hits, and select damage reaction by impact direction/level. Arena movement should be constrained in X/Z and facing should track the opponent. Pinch supported by model-viewer; physical phone gestures not device-tested.
UI library: model-viewer 4.1.0 (vendored from npm/unpkg). Existing local character geometry reused. Fonts use Google Fonts Manrope with local sans-serif fallback.
