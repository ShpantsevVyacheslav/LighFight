# Графика LightFight

Использован встроенный инструмент imagegen. Фотографии служат референсами внешности, костюма и помещения; в игровом рендере исходные фотографии не используются.

## Промпты

assets/generation-prompts.json содержит точные отправленные промпты новых бойцов и пяти арен. assets/generation-prompts-v2.json содержит промежуточную генерацию дополнительных кадров первых трёх персонажей. Неиспользуемые ранние атласы оставлены для истории дизайна. Сведения о финальных атласах первых персонажей добавлены после проверки раскладки.

Материалы локальные. Для игры не нужны внешние библиотеки, шрифты или сетевые запросы.

## Финальные атласы первых персонажей

Игра использует assets/bone-v3-atlas.png, assets/witch-v3-atlas.png и assets/master-v3-atlas.png, созданные заново по исходным фотографиям с требованием 4×4 поз. Точные промпты — assets/generation-prompts-v3.json. Старые оригиналы и версия v2 сохранены, но не используются в игре.

Все восемь игровых атласов содержат 16 поз. assets/sprite-layout.js описывает границы отдельных кадров и смещения относительно центра. scripts/inspect-atlases.cjs получает эти границы из альфа-канала PNG, не меняя пиксели исходных изображений. При рендере масштаб определяется по высоте нейтральной стойки, а стопы привязываются к одной линии пола.
