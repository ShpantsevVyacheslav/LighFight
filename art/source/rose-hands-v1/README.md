# Rose — кисти и скелет

Кулаки перенесены с предыдущего персонажа (генерация по фото руки пользователя).
Крепление приближено к манжете; стыки закрыты сеткой, открытых краёв у запястий: 0.
108378 треугольников; скелет Meshy содержит 24 кости. Все 54061 вершина имеют веса.
Кулаки жёстко закреплены на костях кистей. Текстура кожи скопирована из атласа лица сотрудницы.
Материал запечён в skin-albedo.png 4096px с одним UV-каналом; цветовые маски не экспортируются.
Unity: валидный Humanoid avatar, нормализованные веса, изображение rest.png проверено.
Новая модель пока не проверена на iPhone. Волосы и исходные PBR-карты требуют дальнейшей работы.

Воспроизведение: fit_rose_fists.py → bake_rose_skin.py → rig_rose_candidate.py → RoseReviewSetup.Run.
Все скрипты находятся в scripts/art; первые три запускаются Blender -b --python-exit-code 1 --python.
Перенос кистей и материалов — 0 кредитов. Remesh и rig — 10 кредитов из текущего лимита 400.
