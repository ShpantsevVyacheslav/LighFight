# Двор — первый объёмный вариант

Основа: assets/references/photo-05.jpg. Размеры выведены приблизительно из одного ракурса, не измерены.
Сохранены серая стена, бордовая дверь/перила, лестница, парковка и деревья.
Игровая площадка 12 × 8 м намеренно расширена; машины вынесены за её пределы.
Это редактируемая Blender-сцена, не окончательная графика: требуется заменить условные автомобили и кроны, добавить поверхности гравия, кладку, листья и освещение Unity.
Стоимость Meshy: 0. В текущую сборку LighChat этот черновик не включён.
Воспроизведение: Blender -b --python-exit-code 1 --python scripts/art/build_courtyard.py.
