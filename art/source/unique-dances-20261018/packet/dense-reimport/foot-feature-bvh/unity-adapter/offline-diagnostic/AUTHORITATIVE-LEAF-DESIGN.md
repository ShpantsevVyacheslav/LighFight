## Conservative bound audit

For each node, double intervals enclose each original w*p coordinate and w translation coefficient; signed row endpoints give a lower bound of the real weighted sum. Magnitude M sums absolute row coefficient times maximum absolute feature endpoint. The original expression has at most4 influences × (3 multiplies +3 dot additions +1 weight multiply +1 accumulation) =32 float operations. gamma64*M therefore exceeds the standard forward absolute error allowance for this expression, including its possible wider intermediates; cancellation does not undermine the absolute bound. The existing double gamma32 allowance covers construction-product and16-term interval evaluation errors. Its lower return subtracts these allowances, so the observed1ULP is included without altering equality/acceptance criteria. The1e-30 absolute guard exceeds even32 float min-normal FTZ losses; it is a conservative pruning margin, never a parity epsilon. Unweighted row/bind magnitude is separately rejected above float.MaxValue/16 before queries, weighted node magnitude above float.MaxValue/64, preventing tiny weights from hiding overflowing dot intermediates. Nonfinite results fail closed.

Constraints: delegates must evaluate exactly the same immutable original point set/order/weights supplied to construction and have no side effects; arbitrary user-supplied arithmetic is not justified by this bound. Point mutation/changed influence identity invalidates the construction contract, as before. Only the narrowly audited original expression is selected by the review adapter. Tests still need actual Unity full parity, multiple poses/signed affine/cancellation and no incorrect pruning; no GC-zero or performance claim.
