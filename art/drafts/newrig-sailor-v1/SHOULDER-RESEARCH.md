# Shoulder / loose garment correction research

This is a design/proof guide, not a claim that any product's method automatically fixes this model.

- [Reallusion Character Creator5: Arms Layer for Transferring Skin Weight](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/08-Creating-Custom-Assets/Arms-Layer-for-Transferring-Skin-Weight.htm) demonstrates splitting sleeve vertices from the body into a lateral Arm Layer before repeating weight transfer to address cloth stretching. Application here: inspect NEW autoheat/transfer arm-versus-torso weights in sleeve, axilla and collar regions. The earlier native67-bone neck-leak audit does not prove anything about this new160-DEF solve. Geometry-based region labels must be inspected; do not blindly strip all chest influence from a sleeve or arm influence from a shoulder seam.
- [Epic: MetaHuman Stylized Character Body Rig Editing](https://dev.epicgames.com/documentation/metahuman/metahuman-stylized-character-body-rig-editing) explains garment-specific corrective-joint placement and pose/RBF adjustment, starting with extreme poses and verifying intermediate poses. The clothed surface, rather than hidden anatomy alone, determines a suitable corrective position. This is evidence for a few designed shoulder correctives rather than endless smoothing. We do not have or claim MetaHuman/RigLogic compatibility.
- [Autodesk: Create pose space deformations](https://help.autodesk.com/cloudhelp/2023/ENU/Maya-CharacterAnimation/files/GUID-00699C13-8CA1-450C-937D-57C7B3DFD8C6.htm) describes associating corrective blend shapes with joint poses to fix deformation problems. [PSD overview](https://help.autodesk.com/cloudhelp/2023/ENU/Maya-CharacterAnimation/files/GUID-45D389D6-B8E4-4225-B27B-9927BB61C28D.htm) describes interpolating joint transformations to drive those shapes. We can implement equivalent portable morph targets + baked animation weight curves locally; a Blender-only live modifier is not a game-ready solution.

## Next local experiments

1. Finish the actual full-body+shoulder gallery on unchanged dense model/new rig: boxing3, kick3, head reaction2, walk2, dance3. Map root displacement and legs/feet/toes/fingers. Keep explicit limitations for noIKgrounding/facial retarget. This reveals regressions instead of optimizing one dance screenshot.
2. Quantify NEW weight partition in collar/axilla/sleeves. If actual spill exists, make a versioned sleeve/torso mask and targeted correction, then compare all gallery poses; never a universal other-actor mask.
3. Design a small localized cap corrective at the genuinely problematic pose. Preserve neckline/central chest, head/neck and distal arm exactly. Use a continuous convex cap contour derived from the actual garment cross-section, with smooth falloff. Avoid Laplacian tangential sliding that produced texture gathering in rejectedv6. Invert the final weighted skin matrix to express the posed sculpt as a rest-space morph delta. A numerical envelope parameter is a candidate art choice, not anatomical truth or automatic acceptance.
4. Review before/after front andthreequarter; reject if notch, collar drift, rubbery UV or collapsed deltoid. Only if improved, split into2–8localized targets, interpolate from actual joint pose, test shoulder twist/elevation and every native motion plus intermediate frames. No per-frame fullmesh target explosion. Skin weights remain max4 and base original vertices/topology/UV/maps remain exact.
5. Export only a validated version. Keep control rig separate from gameDEF bones and prune unused facial/tongue chains only after demonstrating pose-equivalent deformation. Full dense mobile performance is separate and unproven; no phone heat or production acceptance claim.
