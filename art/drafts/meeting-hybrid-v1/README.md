# Переговорная — промежуточный переносимый мастер

**REVIEW ONLY: ещё не отрендерен и не перенесён в игру.**

Мебель — исходная генерация Tripo по нашему photo-03; её буфер геометрии, UV, нормалей, индексов и оригинальных карт скопирован без изменений. Стены/пол/два окна с радиаторами/доска/потолочная сетка построены отдельно по видимым признакам настоящего фото. Это гибридная сборка, не заявление, что Tripo сгенерировал всё помещение.

Масштаб мебели выбран для высоты группы1.4м. Размеры комнаты6.8×7×3м — расширенное игровое пространство, не измерения по фотографии. Ближняя линия боя отделена от мебели; правая/передняя стороны открыты для просмотра. Число и форма кресел унаследованы от исходной генерации; точность реконструкции ещё не принята.

`tools/build_portable.py` повторяет сборку без Blender/Unity и проверяет исходный SHA, неизменность полного исходного binary payload и всех карт. `manifest.json` фиксирует происхождение, трансформацию, свободную линию боя и SHA мастера. Большой GLB — локальный проверочный артефакт, не готовый мобильный ресурс.

Далее нужны реальные кадры переносимого GLB, визуальная проверка деталей/ракурса, коллизии, бюджет окружения и Unity-интеграция. Исходные персонажи и их детализация этой работой не затронуты.

Текстура пола создана Imagegen по материалу пола настоящего photo-03 и отдельно отмечена в `textures/provenance.json`; это не часть Tripo-генерации и не исходная фотография. PNG сохраняется без изменения. Первые рендеры с неверной camera-basis и зеркальным расположением окон сохранены как RED; исправленная архитектура ещё не перенесена в игру.
