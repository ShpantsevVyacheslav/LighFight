# LighFight: проверка внутри Game Hub LighChat

Актуальный путь с 2026-10-11: LighChat → нижняя вкладка с геймпадом →
«Играть» → карточка LighFight. Это тот экран с Дураком, Морским боем,
Шашками и Шахматами, который показал владелец. Отдельное приложение
LighFight Art Review для этой проверки не требуется.

## Что подготовлено

У LighChat уже есть LighFightHubTile и Flutter/native Unity host. Код карточки
не меняется. Тестовый профиль Unity использует тот же protocolVersion 1, mode bot
и анонимный sessionId; нативные мосты остаются прежними. В этой тестовой сборке
карточка открывает графический стенд, а не бой. Обычный профиль игры сохранён.

Сцена `Assets/LighFight/Scenes/HostArtReview.unity` содержит актуальный Meshy
персонаж, 24 кости, исправленные нормали, сжатые кулаки и HostBridge.
Анимация ждёт Launch от LighChat; кнопка «В Game Hub» вызывает HostBridge.Exit,
после чего существующий iOS bridge unloadApplication возвращает окно LighChat.
Выполнение этого нативного перехода на устройстве пока не подтверждено.

Профиль `LIGHFIGHT_EMBED_ART_REVIEW=1` включает графические ресурсы непосредственно
в тестовый UnityFramework. Это временный стенд: не изменение схемы доставки
боевых ресурсов через Addressables/CDN. Не публиковать этот профиль как игру.

## Сборка — агент «Нативная лента IOS»

Не выполнять старый ExportIosReview: он создаёт отдельное приложение и выбирает
исходную сцену. Использовать общий экспорт Unity as a Library с новым профилем.

```sh
env UNITY_EDITOR=/Applications/Unity/Hub/Editor/6000.3.26f1/Unity.app/Contents/MacOS/Unity LIGHCHAT_ROOT=/Users/macbook1/Desktop/LighChat LIGHFIGHT_EMBED_ART_REVIEW=1 LIGHFIGHT_EMBED_PROTOTYPE=0 /Users/macbook1/Documents/ChatGPT/LighFight/scripts/build-host-libraries.sh ios
```

Скрипт экспортирует Unity в `unity/Builds/iOS`, собирает UnityFramework Debug и
копирует его вместе с Data в `mobile/packages/lighfight_host/ios/Frameworks`.
После этого требуется pod install с LIGHFIGHT_IOS=1:

```sh
cd /Users/macbook1/Desktop/LighChat/mobile/app/ios
env LIGHFIGHT_IOS=1 pod install
```

Далее агент собирает и устанавливает обычный staging LighChat по актуальному
рецепту `backlog/native-feed-handoff.md` со всеми флагами функций. LIGHFIGHT_IOS=1
должен присутствовать и при Flutter build, иначе следующий pod install может
исключить UnityFramework. Нового bundle ID для владельца не создаём.

В текущую установленную сборку эти исходники автоматически не попадают.
Если карточки нет — сначала проверить наличие встроенного UnityFramework:
существующий isAvailable скрывает карточку в сборках без runtime.
Не делать карточку видимой принудительно при отсутствии Unity.

## Проверка владельцем — 10–15 минут

1. Открыть LighChat → геймпад → Играть → LighFight; убедиться, что показываются
   новые кулаки, доступен поворот камеры и пауза.
2. Нажать «Локти / кисти», скорость ¼. Посмотреть удар и возврат сбоку/сверху/спереди:
   пальцы сомкнуты, большой палец снаружи, нет дыр, запястье не отрывается, часы
   не растягиваются, кожа не меняет резко цвет у стыка.
3. Осмотреть локти, икры/колени и весь персонаж; оценить форму и одежду.
4. Нажать «В Game Hub»: вернуться на ту же вкладку Играть, карточка перестаёт
   быть занятой. Снова открыть LighFight; повторить цикл три раза.
5. После выхода открыть чат и отправить обычное сообщение; проверить, что
   экран, клавиатура и ориентация LighChat работают.
6. Внутри просмотра свернуть приложение и вернуть, затем выйти в Game Hub.
7. Оставить анимацию на пять минут: отметить нагрев, рывки и вылеты. FPS/память
   измеряет агент инструментами; субъективная плавность не заменяет замер.

Результат: скриншот/запись дефекта, ракурс, момент анимации и выбранная модель.
Это один персонаж и один джэб; противник, бой, арены и открытие пальцев здесь
не ожидаются. Возможность игры при входящем звонке требует отдельной проверки.

## Проверки и ограничения

HostArtReviewSetup.Verify проверяет сцену и обнаруживает отсутствие HostBridge.
Unity runtime test проверяет ожидание Launch, выбор кандидата, анимацию и одно
событие Exit с сохранением sessionId. Отключение Exit должно ломать этот тест.
Сборка UnityFramework, Flutter device build, установка и возврат нативного окна
на iPhone в этой задаче не выполнялись.

Проверено 11 октября 2026: Unity 47/47, Flutter test/features/lighfight 8/8.
Удаление HostBridge обнаружено проверкой сцены. Отключение host.Exit ломает
тест возврата; после восстановления тест проходит. Проверка на устройстве остаётся.
