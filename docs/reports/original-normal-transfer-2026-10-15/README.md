# Original 4K normals onto native geometry — offline preparation

Status: mathematical feasibility only. No replacement atlas, no renderer acceptance, no main changes. No Blender, Unity or player was launched for this task. Cobalt is the first target; no inferred correction is applied to any other role.

The source original is 1,966,715 triangles, native 99,999. A normal texture can recover shading detail, not silhouette, physical geometry, cast-shadow detail or source deformation. Direct original-map replacement is rejected because both UV correspondence and tangent frames differ.

## Reproduce the bounded CPU diagnostic

Use Python with numpy and Pillow. Run `python -m unittest discover -s .tools/tripo-dense-review/OriginalNormalTransferReview -p 'test_*.py'`; run `python .tools/tripo-dense-review/OriginalNormalTransferReview/sample_transport_diagnostic.py` from repository root. The script uses existing saved 11,057-point correspondence, verifies the normal-image hashes and produces diagnostic JSON only. Existing RED and GREEN logs are retained. Six mathematical tests pass.

At 10,878 valid samples, baseline native normal versus approximate original frame has angular median 4.853°, p95 32.982°. Transported RG8 median .1853°, p95 .2877°. Including 179 baseline fallbacks, transported p99 is 7.429°; baseline p99 55.091°. Direct original 4K at native UV is worse: median 6.458°, p95 39.408°. These use saved UV-derivative frames and raw RGB signed vectors. They are NOT actual Unity packed-normal/shader comparisons and cannot substantiate a restored-detail claim. See `sample-diagnostic.json` for all samples, thresholds, source paths and hashes.

For column bases A=original[T B N], B=native[T B N], transport is q=normalize(inverse(B)*normalize(A*n)). A transpose is invalid for interpolated nonorthogonal frames. Singular frames, nonfinite vectors and q.z<=0 are rejected; native baseline is retained there. Mirrored handedness comes from measured tangent.w and object determinant, never a guessed green-channel inversion. Six tests cover these cases and RG8 quantization.

## Actual shader contract, locally inspected Unity 6000.3.26f1

`Contents/Resources/CGIncludes/UnityStandardConfig.cginc:67` defaults `UNITY_TANGENT_ORTHONORMALIZE` to0. `UnityStandardCore.cginc:93` has an optional per-pixel orthonormalization branch; the actual compiled variant must be recorded, not assumed. Standard normalizes the final T*x+B*y+N*z world normal. `UnityStandardUtils.cginc:153` forms B=cross(N,T)*tangent.w*unity_WorldTransformParams.w. Preserve vertex transformations and perspective interpolation, including the per-vertex normal transform.

`UnpackScaleNormalRGorAG` has distinct RGB, ASTC and RG/AG branches. RGB uses XYZ; ASTC reconstructs Z before strength, RG/AG after strength. At strength1 those orders coincide, but encoding and compression still require the actual target shader probe. Original source import/reference settings must be recorded too. A signed RGB CPU oracle is insufficient. Native positive-Z representation cannot encode all transformed source normals; reject/fallback rather than silently clamp a negative hemisphere.
