# Return player block — local verification

A toggle button sits above the movement joystick and mirrors with left-handed controls. Tap again or start an accepted attack to release block; rejected attacks preserve it. Space remains a held desktop control. Pause/background/reset clear the latch. Core movement retains its guard speed penalty.

Evidence: core negative control then 91/91 passing; visible-control negative control then 2/2 passing; full Metal EditMode 237/237; selected-content PlayMode 8/8. Layout checks cover both handedness settings and supported scales, joystick clearance and crouch separation.

This is a first functional control candidate, not user acceptance of ergonomics. Actual phone testing, final controller design, crouched protection and guarding while retreating remain open. No animation or artist asset was changed by this patch.
